## Files

### `python_basics.py`

A collection of introductory Python exercises demonstrating basic syntax and programming concepts.

Examples include:

```python

numbers = np.array([1, 2, 3, 4, 5])
print(numbers)
```
Additional exercises demonstrate functions, loops, conditional logic, variables, collections, and basic data-type operations.
