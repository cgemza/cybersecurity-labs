
# Cybersecurity Labs

This repository documents hands-on cybersecurity exercises and technical skills developed while completing the **Google Cybersecurity Professional Certificate**. Areas of study include security foundations, network security, Linux, SQL, threat and vulnerability management, detection and response, and Python automation.

## About This Repository

The purpose of this repository is to document practical experience with cybersecurity tools, concepts, and techniques through hands-on labs and exercises.

Topics include:

- Linux command-line administration
- File and directory management
- User, group, and permission management
- SQL and security-related database queries
- Network security and traffic analysis
- Security monitoring and incident detection
- Python scripting and cybersecurity automation
